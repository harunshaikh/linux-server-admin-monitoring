# Linux Server Administration & Monitoring Lab


A hands-on Linux administration project focused on basic server management, monitoring, troubleshooting, and Bash scripting using Ubuntu Linux.


## Skills & Technologies


- Linux (Ubuntu)
- Bash / Shell Scripting
- Git & GitHub
- Basic Networking
- SSH
- Nginx
- systemd
- APT

- Linux user and group management
- File permissions and ownership
- Package management using APT
- Service management using systemd
- CPU, memory, process, and disk monitoring
- Basic networking and SSH
- Basic Bash scripting
- Linux troubleshooting
