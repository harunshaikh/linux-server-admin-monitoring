# Basic Networking & SSH

## Commands Used

### IP Address
ip addr

Used to view network interfaces and IP addresses.

### Connectivity
ping -c 4 8.8.8.8

Used to test network connectivity.

### DNS
ping -c 4 google.com

Used to verify DNS resolution.

### Ports
ss -tuln

Used to view listening TCP and UDP ports.

### SSH
ssh -V
sudo systemctl status ssh

Used to check SSH availability and service status.

## Practical Work

- Checked network interfaces and IP addresses.
- Tested network connectivity.
- Verified DNS resolution.
- Checked listening ports.
- Checked SSH service status.
